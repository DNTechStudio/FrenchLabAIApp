# Data Model & State Lifecycle: Practice Mode & AI Elevation

**Feature**: `003-practice-mode-ai-improvement`  
**Date**: 2026-09-28  

---

## 1. Core Domain Entities

### 1.1 `AppMode`
Enumeration of the global application operational modes:
```typescript
type AppMode = 'test' | 'practice';
```

### 1.2 `CefrLevel`
Supported CEFR proficiency levels:
```typescript
type CefrLevel = 'A1' | 'A2' | 'B1' | 'B2' | 'C1' | 'C2';
```

### 1.3 `PracticeSession`
The encapsulated state of a candidate's practice workout:
```typescript
interface PracticeSession {
  id: string;                      // Unique ID (e.g. 'prac-1727550000000')
  createdAt: number;               // Unix timestamp
  topic: PracticeTopic | null;     // Selected or custom prompt
  audioBlobId?: string;            // AudioStore reference ID
  audioDuration: number;           // Recorded speech duration in seconds
  originalTranscript: string;      // Speech-to-text output (editable)
  selectedLevels: [CefrLevel, CefrLevel]; // Exactly 2 levels (e.g. ['B1', 'B2'])
  elevationResult?: ElevationResult | null;
}
```

### 1.4 `PracticeTopic`
Prompt or theme for spontaneous practice:
```typescript
interface PracticeTopic {
  id: string;
  title: string;
  category: string;
  sampleQuestions: string[];
}
```

### 1.5 `ElevationResult`
The output generated by `PracticeElevationEngine`:
```typescript
interface ElevationResult {
  id: string;
  generatedAt: number;
  originalTranscript: string;
  elevations: {
    level1: LevelElevation;
    level2: LevelElevation;
  };
  comparisonHighlights: UpgradeHighlight[];
}

interface LevelElevation {
  level: CefrLevel;
  rewrittenText: string;
  connectorsUsed: string[];
  syntacticStructures: string[];
  pedagogicalSummary: string;
  lexicalUpgrades: {
    original: string;
    elevated: string;
    explanation: string;
  }[];
}

interface UpgradeHighlight {
  fromSnippet: string;
  toSnippet: string;
  targetLevel: CefrLevel;
  category: 'vocabulary' | 'syntax' | 'connector' | 'register';
  reason: string;
}
```

## 2. State Machine: Practice Workflow Lifecycle

```
[INIT] 
   │
   ▼
[TOPIC_SELECTION / PROMPT INPUT]
   │
   ▼
[VOICE_RECORDING] ──(SpeechRecognizer)──► [LIVE_TRANSCRIPTION]
   │
   ▼
[TRANSCRIPT_REVIEW_AND_EDIT]
   │
   ▼
[CEFR_DUAL_LEVEL_SELECTION] (Must choose exactly 2 levels)
   │
   ▼
[AI_ELEVATION_COMPUTING] (Améliorer avec l'IA)
   │
   ▼
[COMPARATIVE_REVIEW_AND_SHADOWING] (TTS Audio playback & Pedagogical Highlights)
```

## 3. Storage & Persistence Mapping

| Key | Format | Purpose |
|---|---|---|
| `delf_speaking_active_mode` | String (`'test'` or `'practice'`) | Remembers active mode across browser sessions. |
| `delf_speaking_practice_session` | JSON (`PracticeSession`) | Persists active practice recording buffer and elevation output. |
| `delf_speaking_selected_levels` | JSON (`[CefrLevel, CefrLevel]`) | Remembers preferred dual CEFR comparison pair. |
